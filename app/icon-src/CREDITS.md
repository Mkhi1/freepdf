# Icon credit

The Free PDF icon is an adaptation of this photo:

- Photo: "A common hoopoe - Wiedehopf 02" by Zeynel Cebeci
- Source: https://commons.wikimedia.org/wiki/File:A_common_hoopoe_-_Wiedehopf_02.jpg
- Licence: CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0

Changes: cropped to the head, background removed, redrawn with an engraving filter on a colour tile. The icon is shared under the same licence.

To rebuild it: run `photo_icon.py source.jpg icon-1024.png`, then `install_icon.py icon-1024.png ..`.
